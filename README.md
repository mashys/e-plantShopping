# e-plantShopping - Paradise Nursery

A React-based e-commerce shopping application for Paradise Nursery, where users can browse and purchase a variety of plants.

## Features
- Browse plants across multiple categories: Air Purifying, Aromatic Fragrant, Insect Repellent, Medicinal, and Low Maintenance
- Add plants to a shopping cart
- View and manage cart items (increment, decrement, remove)
- Real-time cart total and item count updates
- Global state management using Redux Toolkit

## Technologies Used
- React
- Redux Toolkit
- Vite
- GitHub Pages
